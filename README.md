# ASCENSION 0.7 — портреты E-ранга

На основе ASCENSION 0.6. Добавлено 10 иллюстрированных портретов E-ранга: 5 классов × 2 пола. Иллюстрации извлечены из единого концепт-листа, поэтому возможны остаточные декоративные элементы в кадре. Это временный арт для MVP, не финальные индивидуальные иллюстрации.

Ранги D–S пока используют прежние SVG-заглушки. Экипировка влияет на характеристики, но не на портрет. Сохранение: localStorage `ascension-demo` — не очищайте данные сайта.

Windows CMD:

    cd /d C:\ascension-v07\ascension-v07
    npm install
    npm run dev

Откройте http://localhost:5173/
